PLACEHOLDER FILES NEEDED
========================

Please add the following files to this directory:

1. resume.pdf
   - Your professional CV/Resume in PDF format
   - This will be downloaded when users click "Download CV" button

2. favicon.ico
   - 16x16 or 32x32 px favicon
   - Use favicon.io to generate from your logo/initials

3. favicon-16x16.png
   - 16x16 px PNG favicon

4. favicon-32x32.png
   - 32x32 px PNG favicon

5. apple-touch-icon.png
   - 180x180 px PNG for iOS devices

6. images/ directory (optional)
   - Create images/profile.jpg for your professional photo
   - Create images/projects/ for project screenshots
   - Create images/whatsapp-demo.gif for chatbot demo

Generate favicons at: https://favicon.io/

Once you add these files, delete this PLACEHOLDER_README.txt file.
